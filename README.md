# 2024 CUMCM C 题 农作物种植策略优化

本项目针对 2024 年高教社杯全国大学生数学建模竞赛 C 题“农作物的种植策略”，研究华北山区乡村在 2024–2030 年间的农作物种植规划。项目以利润最大化为目标，在土地类型、种植季次、轮作、豆类作物种植频率、市场容量和管理便利性等约束下，构建多阶段种植优化方案。

## 问题背景

研究对象包含 1201 亩露天耕地、16 个普通大棚和 4 个智慧大棚，共 54 个地块及大棚单元，涉及 41 种农作物。不同土地类型具有不同的种植制度：

- 平旱地、梯田和山坡地通常每年种植一季粮食作物。
- 水浇地可选择一季水稻或两季蔬菜。
- 普通大棚适合一季蔬菜和一季食用菌。
- 智慧大棚可种植两季蔬菜。
- 同一作物不能在同一地块连续重茬；每个地块在连续三年内至少种植一次豆类作物。

## 建模方法

### 数据处理与探索

`src/Data Processing.py` 对原始耕地、作物和 2023 年种植数据进行缺失值填充、重复值检查、异常值检查、表连接和产量计算，并生成清洗后的 CSV 数据。脚本还包含不同地块类型、作物类型、种植季次和销售价格的探索性分析。

### 问题一 稳定条件下的种植优化

在预期销售量、亩产量、种植成本和销售价格保持 2023 年水平的条件下，使用 PuLP 建立线性规划模型，对两种销售情景进行比较：

1. 超过预期销售量的部分滞销并浪费。
2. 超过预期销售量的部分按正常价格的 50% 销售。

模型考虑地块容量、作物适种范围、轮作、豆类作物种植频率、季次和销售量上下限等约束。

### 问题二 不确定条件下的种植优化

使用固定随机种子模拟 2024–2030 年的市场和生产波动，包括：

- 小麦、玉米预期销售量年增长 5%–10%。
- 其他作物预期销售量每年波动约 ±5%。
- 亩产量每年波动约 ±10%。
- 种植成本平均每年增长 5%。
- 蔬菜价格增长、食用菌价格下降。

在模拟参数基础上重新求解各类土地和作物的利润最大化方案。

### 问题三 相关性与替代性情景

论文讨论了作物间的替代性和互补性，以及预期销售量、销售价格和种植成本之间的相关关系。探索性分析记录的种植成本与销售单价相关系数约为 0.76。实现代码据此调整参数并再次执行种植优化，用于比较相关性情景与问题二方案的差异。

## 主要结果

- 四组 Excel 结果文件均覆盖 2024–2030 年，并按年度给出地块和作物的种植面积安排。
- `src/Q2.py` 中记录的问题二五类作物七年利润合计约为 55,699,404.69 元。
- `src/Q3.py` 中记录的相关性调整情景利润合计约为 62,769,604.24 元，比问题二情景增加约 7,070,199.55 元，增幅约 12.69%。

## 运行环境

建议使用 Python 3.9 或更高版本：

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

主要模型脚本是由 Jupyter Notebook 导出的顺序式 Python 文件，可分别运行：

```bash
python src/Q1.py
python src/Q2.py
python src/Q3.py
```

## 已知限制

- `src/Data Processing.py` 原本依赖竞赛附件中的两个原始 Excel 文件；本仓库提供的是由这些附件导出的清洗后 CSV 数据。
- 优化脚本保留了竞赛期间的分段建模和硬编码参数，尚未重构为统一的命令行程序。
- 问题二和问题三采用固定随机种子生成情景；结果反映特定模拟路径，不代表所有不确定情景。
- 论文提出多元回归分析框架，但现有问题三脚本主要实现基于相关性假设的参数调整与线性规划比较。

## 文件说明

- `results/result1_1.xlsx`：超产部分滞销情景。
- `results/result1_2.xlsx`：超产部分按 50% 价格销售情景。
- `results/result2.xlsx`：考虑销售量、亩产量、成本和价格不确定性的方案。
- `results/result3.xlsx`：考虑相关性和作物替代性的扩展情景。
